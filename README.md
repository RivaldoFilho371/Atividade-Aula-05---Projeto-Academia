# Atividade-Aula-05---Projeto-Academia

## Descrição

Este projeto é uma atividade referente à aula 05 de Desenvolvimento Front End, contendo 11 páginas. Cada Página contém informações sobre uma academia fictícia chamada "Olympia Prime". Atenção: Todas as informações contidas são meramente fictícias, não contendo nenhum tipo de veracidade, ademais, o projeto é para fim acadêmico, sem servir nenhum propósito comercial.

## Requisitos

Para executar e editar o projeto, é necessário ter:

* **Sistema operacional:** Windows 10 ou superior
* **Visual Studio Code:** versão 1.80 ou superior
* **Navegadores compatíveis:**

  * Google Chrome 100 ou superior
  * Microsoft Edge 100 ou superior
  * Mozilla Firefox 100 ou superior

## Extensões necessárias do VS Code

Para poder visualizar o projeto e editá-lo em tempo real, é necessário instalar as seguintes extensões no Visual Studio Code:

* **Live Server**
* **IntelliSense for CSS class names in HTML**
* **Open Browser Preview**

## Como executar o projeto

1. Abra a pasta do projeto no **Visual Studio Code**.
2. Certifique-se de que as extensões necessárias estão instaladas.
3. Abra o arquivo `home.html`.
4. Clique com o botão direito no arquivo e selecione **"Open with Live Server"** no canto inferior direito do seu VS code.
5. O projeto será aberto no navegador.
6. Ao realizar alterações no código e salvar o arquivo, o **Live Server** atualizará a página automaticamente.
